# bovine

A calm local music player for Android.

## Focus

- Native Compose + Material 3 Expressive
- Soft blur (Haze), solid status bar
- Album grid home
- Spotify-style now playing bar (art, title, play/pause, heart → Favorites)
- Swipe up for full now playing (large art + large button)
- Bottom pill for queue, lyrics, volume slider
- Synced lyrics from embedded tags or .lrc
- Optimized for Google Pixel devices
